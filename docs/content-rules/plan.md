# Reglas de contenido: /plan

**Objetivo:** sugerencias concretas de actividades para hacer en grupo (quedadas, excursiones, noches temáticas).

**Tono:** neutro y positivo. Los planes deben ser realistas: nada carísimo, nada ilegal, nada que requiera equipamiento muy especializado que la mayoría de grupos no tendría.

**Formato:** frase imperativa dirigida al grupo — "Organizad...", "Proponed...", "Montad...".

**No solapar con:** `/reto` (reto son retos individuales dentro del chat; plan son propuestas de quedada real fuera del chat).

**Placeholder `{name}`:** no se usa (el plan es para el grupo, no para una persona).
