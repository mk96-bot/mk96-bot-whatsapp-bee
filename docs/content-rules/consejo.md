# Reglas de contenido: /consejo (comando secreto)

**Objetivo:** un consejo random para quien escribe, mezclando consejos serios (autoestima, descanso, límites) y consejos desenfadados/random del día a día.

**Es un comando secreto:** mismo tratamiento que `/hola`.

**Regla dura:** nunca consejos médicamente arriesgados, ni consejos financieros o legales que se puedan tomar en serio como asesoramiento real. Es entretenimiento, no terapia ni asesoría.

**Tono:** puede alternar entre serio ("Consejo serio: ...") y random/gracioso ("Consejo random: ..."), usando esos prefijos como ya se hace en el archivo actual para que quede claro el registro.

**Placeholder `{name}`:** obligatorio en cada frase.

**No solapar con:** `/piropo` (piropo no aconseja, solo halaga) ni `/suerte`/`/destino` (esos son predicciones, no consejos).
