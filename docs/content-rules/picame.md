# Reglas de contenido: /picame (archivo aguijon.json, comando secreto)

**Objetivo:** una "pulla" cariñosa y claramente en broma sobre manías o torpezas cotidianas universales. (Este comando se llamaba antes `/aguijon`; el nombre del archivo de contenido sigue siendo `aguijon.json`, solo cambió el comando.)

**Es un comando secreto:** aparece listado en `/ayuda` y `/presentate`, pero sin descripción real — solo el teaser genérico "🤫 pruébalo y lo descubrirás".

**Regla dura (temas prohibidos):** nunca sobre aspecto físico, peso, inteligencia, dinero real, orientación sexual, salud mental o cualquier característica identitaria. Solo manías conductuales universales y graciosas: impuntualidad, desorden, mala memoria, procrastinación, torpeza con la tecnología, manías de sueño/comida, etc. — cosas con las que cualquiera se puede reír de sí mismo sin sentirse atacado.

**Tono:** de coña entre amigos, nunca cruel. Si una frase nueva podría doler de verdad a alguien, no va aquí.

**Placeholder `{name}`:** obligatorio en cada frase.

**No solapar con:**
- `/confesion` — picame es una pulla que el bot le hace a la persona, no una pregunta para que la persona confiese algo.
- `/abeja` — no confundir: `/abeja` es el picante de atracción/ligoteo (antes se llamaba `/picame`); este comando (`/picame` ahora) es la pulla cariñosa sobre manías, sin nada de atracción.
